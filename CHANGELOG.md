# Changelog

## 0.2.0

Adds typed/no-code generic policy authoring, idempotent submit-once handoff and a separately released independent Windows publisher. Required console commands, a plain SemVer file, protected controllers, local root exclusivity, renewable fenced leases, atomic main/receipt publication and exact verification are implemented. Original-request continuation preserves clean recorded candidates, versions, receipts and attempts; uncertain/dirty/conflicted states remain actionable. Inspection remains read-only and now understands the native protocol as well as the legacy adapter. Consumer installation and runner adoption remain manual.

## 0.1.1

Failed records without blocker text now retain an explicit missing-evidence finding and an actionable operator remedy. The viewer still performs no retry or processor operation. Original request metadata remains available unchanged.

## 0.1.0

Initial Editor-only read-only queue/processor/lease/receipt viewer and shared public inspection API. Explicit bounded refresh; no publisher, submission, configuration, retry or recovery actions. Consumer installation is manual. Validation and unsupported surfaces are recorded separately.
