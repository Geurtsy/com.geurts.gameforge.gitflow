# Changelog

## 0.1.1

Failed records without blocker text now retain an explicit missing-evidence finding and an actionable operator remedy. The viewer still performs no retry or processor operation. Original request metadata remains available unchanged.

## 0.1.0

Initial Editor-only read-only queue/processor/lease/receipt viewer and shared public inspection API. Explicit bounded refresh; no publisher, submission, configuration, retry or recovery actions. Consumer installation is manual. Validation and unsupported surfaces are recorded separately.
