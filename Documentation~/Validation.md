## Explicitly unverified or unsupported

Native rendered Editor normal/narrow layout, docking, host light/dark skins, hover/physical keyboard focus and high-DPI review remain unverified. Hidden UI Toolkit controls/trees do not certify pixels or interaction. The user has not authorized interactive desktop testing; perform that review manually in an isolated Editor before claiming native conformance.

The detached acceptance parent and representative required console children check startup console absence. Native launch uses CREATE_NO_WINDOW, suspended job assignment and kill-on-close descendant ownership; credential/GUI installation prompts are suppressed. This does not certify arbitrary third-party GUI/helper trees, which the generic policy excludes unless their owner establishes silent unattended behavior. No desktop input/focus APIs, OS audio mute or saved-volume changes are used. Unity launches with -batchmode -nographics -nosound from startup through shutdown. No end-to-end native focus/pixel claim is made.

Private HTTPS token access, remote branch protections/PR integrations, immutable game releases, native derived identities, general conflict repair, safe whitespace correction, committed-runner upgrade/migration and optional AI repair are not certified/implemented by this generic release. Missing access and rejected protections remain failures. The source package's own PR/main/immutable release process is separate and mandatory. Source publication does not install or update any consumer or configured runner.
